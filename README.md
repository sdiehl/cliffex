# cliffex

An interactive web explorer of [Clifford algebra](https://ncatlab.org/nlab/show/Clifford+algebra) operators across five signatures: $`\mathrm{Cl}(p,q,r)`$ for PGA, CGA, STA, HYP, CMA.

```bash
npx vite --port 8000
```
